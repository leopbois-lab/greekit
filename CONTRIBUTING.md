# Contributing to greekit

Thanks for your interest! Bug reports, ideas and pull requests are all welcome.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repository and create a branch.
3. Add tests for your change. Formulas should be checked against a reference
   (textbook value or finite differences).
4. Run `pytest` and make sure everything passes.
5. Open a pull request with a short description of what and why.

Please keep the library dependency-free and the code readable: clarity beats cleverness.
